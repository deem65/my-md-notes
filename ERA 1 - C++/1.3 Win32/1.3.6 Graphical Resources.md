#### GDI API
*Windows Graphics Device Interface* is an older windows graphics API used for graphical operations. 
- A device context `DC` is a windows managed object containing information needed for graphical operations. It is accusable via a handle (`HDC`).
- `HDC` is an opaque handle. You can't manipulate its internal implementation directly, but rather through the GDI API.
```cpp
HDC dc = GetDC(hwnd); // retrieves a device context for a specifc window
```
#### Resource Ownership
When working with the Win32 API, acquiring resources generally forces you to be responsible for releasing them. 
Different resources have different clean up functions (gay):
- `GetDC()` - `ReleaseDC()`
- `BeginPaint()` - `EndPaint()`
- `CreateCompatibleDC()` - `DeleteDC()`
- `CreateCompatibleBitmap()` - `DeleteObject()`

Instead of manually remembering resource cleanup in every path we use the RAII technique:
```cpp
class WindowDC {
	HWND window; 
	HDC dc;
public:
    explicit WindowDC(HWND hwnd) : window(hwnd), dc(GetDC(hwnd)) { }

    ~WindowDC() {
        if (dc)
            ReleaseDC(window, dc);
    }

    WindowDC(const WindowDC&) = delete;
    WindowDC& operator=(const WindowDC&) = delete;

    HDC get() const {
        return dc;
    }
};```

#### Hotkey Registration
To register a hotkey, use `RegisterHotkey()` function. The function takes takes four arguments and returns nonzero on success.
```cpp
BOOL RegisterHotKey(
	// window receiving hotkey notifications, 
	// or nullptr for the calling thread
    HWND hWnd, 
    
    // id of registered hotkey
    int id,
    
    // required modifier keys 
    UINT fsModifiers,
    
    // virtual key code of the primary key
    UINT vk
);
```
- When a valid handle is supplied, windows posts `WM_HOTKEY` to the message queue of the thread that owns that window. When `nullptr` is supplied, windows posts the message to the message queue of the calling thread.
- The IDs allow the application to distinguish different registered hotkeys. You would usually put these in `constexpr` variables, as in `constexpr int clip_id = 1;`. When windows posts `WM_HOTKEY`, its `wParam` contains the corresponding ID.
- The modifier keys are combined via bitwise OR: `MOD_CONTROL | MOD_SHIFT | MOD_NOREPEAT`
	- `MOD_NOREPEAT` prevents repeated notifications caused by holding the key (auto-repeat).
- Registration isn't guaranteed to succeed. Some combination are reserved by other applications or windows itself.
#### Path
The hotkey delivery path looks like this: 
1. User presses the registered shortcut.
2. `WM_HOTKEY` is added to the thread's message queue with `wParam` set as the registered hotkey ID.
3. Message loop (`GetMessage()` and `DispatchMessage()`).
	- If the hotkey is thread-associated, hotkeys can be handled in the message loop.
4. `window_proc()` recognizes hotkey ID and handles it.
#### Unregistration
To unregister a hotkey, use `UnregisterHotkey()`. The function takes two arguments `hWnd` and `id`.
- `UnregisterHotkey()` returns nonzero on success and zero on failure.
- It must be called by the thread which registered the hotkey.
- Common situations to unregister a hotkey is on application shutdown or hotkey configuration.
- There are two options to handle configurations:
	- Unregister old, attempt to register new and restore old if it fails (simple).
	- Attempt to register new under a different temporary ID, then unregister old only even if it succeeds.

#### Scaling
A minors resolution is not the only factor that affects how an application appears. You could have two monitors with the same resolution, but the second monitor may pack the pixels into a small or larger size. Windows addresses this through *DPI scaling*.
- DPI stands for dots per inch. 
- In windows UI programming, it represents a scaling measurement based on a reference value of **96 DPI at 100% scaling**.
#### Awareness
DPI awareness describes how an application handles display scaling. Windows supports several application handles display scaling:
- DPI unaware -- windows scales the application rendered output
- System DPI aware -- applications use the system DPI
- Per monitor DPI aware -- applications can adapt based on the monitor
- Per monitor V2 -- improved version
##### Querying A Window's DPI
To query a window's DPI windows provides `GetDpiForWindow()`.
- For a per monitor DPI aware window, the result reflects the DPI of the monitor associated with that window. 
- For a DPI unaware window, `GetDpiForWindow()` returns 96 regardless the monitors actual scaling setting.
```cpp
UINT dpi = GetDpiForWindow(hwnd);

if (dpi != 0) {
	// calculate scaling factor
	float scale = static_cast<float>(dpi) / 96.0f; 
}
```
- If a per monitor DPI aware application is open at 100% scaling is dragged onto a 150% scaling monitor, windows notifies us through the message system with a message called `WM_DPICHANGED`. 
	- `wParam` new DPI values packed into the parameter
	- `lParam` pointer to a `RECT` containing a suggestion for window position and dimensions. 
```cpp
case WM_DPICHANGED: {
	// retrieve the new horizontal DPI.
    UINT dpi = LOWORD(wp);
    
	// convert lp to a rect* suggested by windows
    RECT* rect = reinterpret_cast<RECT*>(lp);
	
	// update window position and size
    SetWindowPos(
        hwnd,
        nullptr,
        rect->left,
        rect->top,
        rect->right - rect->left,
        rect->bottom - rect->top,
        SWP_NOZORDER | SWP_NOACTIVATE
    );
    
    // update ui scale and rendering resources
    
    return 0;
}
```
- `SetWindowPos()` only resizes the window geometry. The renderer handles the contents.

#### The Virtual Screen
The *virtual screen* is the a rectangle containing all monitors in the desktop configuration. 
- The primary monitor's top left corner is `(0, 0)`.
- And so, other monitors can occupy negative coordinates. 
- Windows has functions to convert screen coordinates to client coordinates:
	- `ClientToScreen(hwnd, &point)`
	- `ScreenToClient(hwnd, &point)`
#### Monitor Handles
Just like window handles, windows also uses *monitor handles.* They use `HMONITOR` to identify display monitors.
To identify which monitor a window is on, we can use the following function:
```cpp
HMONITOR monitor = MonitorFromWindow(window, MONITOR_DEFAULTTONEAREST);
```
- `MonitorFromWindow()` returns a handle to the monitor with the largest intersection with the window provided. 
- If the window does not intersect any monitor (positioned  outside the visible monitor rectangles), `MONITOR_DEFAULTTONEAREST` chooses the nearest monitor. 
- With `HMONITOR` we can query its information, using `MONITORINFO` which is a win32 struct containing information about a display monitor. Its main members are:
	- `cbSize` size of the struct
		- windows expects us to set this before calling `GetMonitorInfoW()`, because it allows windows the identify the structure size.
			- This isn't automatic because windows receives a pointer to the struct, not a copy of it. This is also because windows accepts different structs, for example `MONITORINFOEXW extended{};` which contains additional information such as device name.
	- `rcMonitor` rectangle covering the entire monitor
	- `rcWork` work area rectangle, generally excluding taskbars.
	- `dwFlags` monitor attributes, including whether its primary
```cpp
MONITORINFO info{};
info.cbSize = sizeof(info);

if (GetMonitorInfoW(monitor, &info)) {
    RECT rect = info.rcMonitor;

    LONG width = rect.right - rect.left;
    LONG height = rect.bottom - rect.top;
```
#### Enumerating Monitors
To discover every connected display, we can use the `EnumDisplayMonitors()` function:
```cpp
BOOL EnumDisplayMonitors(
    HDC hdc, // optional dc
    LPCRECT lprcClip, // optional rect restricting the enumaration
    MONITORENUMPROC lpfnEnum, // callback function pointer 
    LPARAM dwData // value passed to the callback function
);
```
- When `EnumDisplayMonitors()` is called, windows invokes our callback function for each enumerated monitor.
- The callback receives its monitor handle and rect. If the callback function returns true, enumeration continues, if we return false, it stops.
```cpp
#include <windows.h>
#include <iostream>

BOOL CALLBACK monitor_proc(HMONITOR monitor, HDC dc, LPRECT rect, LPARAM data) {
    std::cout
        << "pos: " << rect->left
        << ", " << rect->top << '\n'
        << "res: "
        << rect->right - rect->left
        << " x "
        << rect->bottom - rect->top
        << '\n';
        
    return TRUE;
}

int main() {
    if (!EnumDisplayMonitors(nullptr, nullptr, monitor_proc, 0)) {
        std::cerr << "monitor enumeration failed\n";
        return 1;
    }
}
```

#### Windows Messages
A *windows message* is a notification or request identified by a numeric message code.
- `WM_CLOSE` request to close a window
- `WM_DESTROY` window being destroyed
- `WM_SIZE` window size changed
- `WM_MOUSEMOVE` the mouse has moved
- `WM_HOTKEY` registered hotkey was pressed
The `window_proc()` function in [[1.3.2 Windows]], for example, is a function which windows delivers us the message and we decide what to do with it. 
#### Message Delivering
There are two ways in which windows delivering functions: posted messages and sent messages.
- *Posted messages* go through a thread's message queue.
	- A *message queue* is a mechanism for holding messages until the application retrieves them.
		- Message queues belong to thread's not windows.
			- A GUI thread is a thread that performs user interface work.
			- Windows creates message queues to threads that perform operations that require it.
		- An application can retrieve a message via `GetMessageW()`.
		- `DispatchMessageW()` delivers a retrieved window message to its window procedure. Thread messages with no associated window must be handled directly in the message loop.
	- Message processing isn't strictly FIFO for every message type, windows has special handling for certain messages.
- *Sent messages* don't go through a queue but rather directly to the window procedure using a different mechanism.
#### Message Struct
`MSG` is a win32 struct used to store information about a windows message.
It has many members, but its most important ones are:
- `hwnd` (`HWND`) target window, if relevant
- `message` (`UINT`) identifier
- `wParam` (`WPARAM`) additional message information
- `lParam` (`LPARAM`) additional message information
- `time` (`DWORD`) time
- `pt` (`POINT`) cursor position

#### Code
```cpp
LRESULT CALLBACK window_proc(HWND hwnd, UINT m, WPARAM wp, LPARAM lp) {
    switch (m) {
	    // when window is being destroyed
	    case WM_DESTROY:
		    // add a WM_QUIT to the calling thread's message queue
		    // ...well not exactly. it requests termination using
		    // a specific windows machenicnism.
		    PostQuitMessage(0);
		    return 0;
    }
    // let windows handle if we haven't
    return DefWindowProcW(hwnd, m, wp, lp); 
}
int main() {
	// retrieve handle to the current module
	HINSTANCE instance = GetModuleHandleW(nullptr);

	// window creation code...
	
	MSG m{};
	
	while (true) {
		// arguments: 
		// - where to write the retrieved message
		// - retrieve thread's windows' messages and its own
		// - min message code filter
		// - max message code filter 
		// returns:
		// - positive: a message was retrieved
		// - zero: WM_QUIT was retrieved
		// - -1: error
	    BOOL res = GetMessageW(&m, nullptr, 0, 0);
	    
	    if (res == -1)
	        return 1;
	        
	    if (res == 0)
	        break;
	        
	    // translates a keyboard event to input
	    // for example event may be WM_KEYDOWN
	    // and input may be WM_CHAR
	    // and then adds the input to the message queue
	    // when relevant
	    TranslateMessage(&m);
	    
	    // delivers the message to its windows procedure
	    // by using the information in the message struct
	    DispatchMessageW(&m);
	    
	    // execution resumes in the message loop
	}
}
```
